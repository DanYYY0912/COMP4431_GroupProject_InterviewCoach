# VoxPrep HK — System Usability Scale (bilingual)

**Participant questionnaire / 參加者問卷**
Print pages 1–2 for the participant. Page 3 is the moderator copy and must not be
shown to the participant. / 第 1–2 頁交給參加者；第 3 頁為主持人專用，請勿讓參加者閱讀。

This is the standard ten-item System Usability Scale (SUS) by John Brooke, kept in
its original item order, with a Traditional Chinese (Hong Kong) translation beside
each English statement. Do not reword, reorder, add or remove items: the alternating
positive/negative wording is what makes the score comparable to published SUS results.

> Brooke, J. (1996). SUS: A "quick and dirty" usability scale. In P. W. Jordan,
> B. Thomas, B. A. Weerdmeester & I. L. McClelland (Eds.), *Usability Evaluation in
> Industry* (pp. 189–194). Taylor & Francis. SUS is free to use with acknowledgement.

### Instructions / 指示

**English.** Thank you for trying VoxPrep HK. Please answer the ten statements below
about the system you have just used. For each statement, circle the one number that
best matches your immediate reaction — not what you think the system should be.
There are no right or wrong answers. Please answer all ten statements and do not
discuss them with the moderator until you have finished.

**中文（香港）.** 感謝你試用 VoxPrep HK。請就你剛剛使用過的系統，回答下面十條陳述。
每條陳述只選擇一個最符合你即時感受的數字，無需考慮系統「應該」如何。答案沒有對錯之分。

A flow is **completed** only if T1–T6 are all ticked. A prompt that tells the
participant where to click, which menu to open or what to type is help: record the
task as not completed and stop assisting. See `docs/USABILITY.md`.

### Scoring key / 計分

Odd-numbered items (1, 3, 5, 7, 9) are positively worded: contribution = response − 1.
Even-numbered items (2, 4, 6, 8, 10) are negatively worded: contribution = 5 − response.

```
SUS = (sum of (response - 1) for items 1,3,5,7,9
     + sum of (5 - response) for items 2,4,6,8,10) * 2.5
```

The result is on a 0–100 scale, not a percentage. A participant who circles 3 for
all ten items scores 50 — that is a scoring illustration, not collected data.

### Transfer to the data sheet

One CSV row per participant, answers in questionnaire order:

```csv
participant_id,q1,q2,q3,q4,q5,q6,q7,q8,q9,q10,flow_completed,duration_minutes
```

Enter only what the participant circled. Do not invent, average or fill missing
values; leave the score out of the release evidence if a row is incomplete. Then:

```sh
.venv/bin/python scripts/score_sus.py evaluation/raw/usability_YYYYMMDD.csv \
  --out evaluation/results/usability_metrics.json
```

The scorer refuses empty input and any answer outside 1–5.
